## 安装与依赖
* 加载器：仅限 Fabric 26.2
* Fabric 版本需要安装 [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
* 建议使用 Java 25

## 本项目做了什么
* 修复了一些影响使用的问题
* 修复或移除了失效的组件，添加了更多新组件的支持
* 按照个人喜好，重新规划了标准编辑器的界面
